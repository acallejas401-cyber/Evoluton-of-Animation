# Evolution of Animation and Its Impact on the Entertainment Industry

A static HTML, CSS, and JavaScript exhibition. No Node.js or build step is required.

## Open the project
1. Extract this folder to your computer.
2. Open the folder in Visual Studio Code.
3. Open `index.html` with Live Server (right-click the file → **Open with Live Server**).

## Files
- `index.html` — page structure and educational content.
- `styles.css` — black theme, responsive layout, timeline, chapter cards, gallery, and portraits.
- `script.js` — interactive timeline, mobile navigation, and six independent Sketchfab viewers.
- `assets/milestones/` — locally stored illustrations used by the interactive timeline.

## Interactive timeline
Select any of the five milestone buttons to update the illustration, title, explanation, and “Why it matters” note.

## 3D gallery
There are six independent model slots: one featured large viewer and five supporting viewers. For each slot:
1. Enter a display name.
2. Paste a Sketchfab model page link or full embed URL.
3. Select **Load model**.

The creator must permit embedding. The page needs an internet connection to load Sketchfab models and portrait images. Loading six models at once may be slow on a weaker connection.

## Portrait images and credits
The Creative Minds portraits are linked from Wikimedia Commons. Each portrait includes a link to its file page; check the individual page for license and attribution terms before reusing it elsewhere. If a portrait does not load, the card retains its initials as a visual fallback.

## Safe editing workflow
Keep a copy of the working folder before making major changes. Save edits in VS Code; Live Server refreshes the page after changes are saved.
